Renders any Lucide icon by name — Rumbo's only icon system (16px, stroke 2, currentColor).

```jsx
<script src="https://unpkg.com/lucide@0.469.0/dist/umd/lucide.min.js"></script>
<Icon name="Camera" />
<Icon name="TriangleAlert" size={20} color="var(--color-error)" />
```

Common Rumbo icons: Camera, CarFront, Bell, ChartColumn, PlusCircle, Fuel, Wrench, ShieldCheck, TriangleAlert, CheckCircle2, Clock3, WalletCards, CircleDollarSign, ArrowRight, RefreshCw, LogOut, Sparkles, FileUp, Building2.
